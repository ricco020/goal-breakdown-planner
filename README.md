# Goal breakdown planner

Free, single-file browser tool for any goal you can count (savings, debt left, weight, pages, sales). Enter the starting number, the target and the finish date: it dates a milestone at the end of every month, gives the weekly pace, says whether you are ahead or behind today and re-plans the next 12 weekly checkpoints from where you really are. If-then plans, print and CSV export.

Live: https://ricco020.github.io/goal-breakdown-planner/

Printable version of the same method: [goal planner](https://tidysheets.shop/p/goal-planner-printable).

MIT licence. No network calls, the plan stays in localStorage.
